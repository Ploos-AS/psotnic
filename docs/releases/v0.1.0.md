# Psotnic container v0.1.0

Initial Ploos AS container release for Psotnic.

## Included

- upstream Psotnic 0.2.14 pinned to commit `b598a8dc25686e2785fb0f9970103cb6a39cdaa6`
- dynamic build with SSL support
- Alpine 3.22 runtime
- non-root UID/GID 1000
- persistent `/data`
- safe first-run idle behavior when no configuration is present
- `PSOTNIC_CONFIG` configuration path override
- `tini` as PID 1
- process healthcheck
- Docker Compose example
- rootless Podman Quadlet example
- multi-architecture publication for `linux/amd64` and `linux/arm64`
- BuildKit SBOM and provenance attestations
- MIT packaging license with upstream GPL-2.0-or-later attribution

## Image

`ghcr.io/ploos-as/psotnic:0.1.0`
